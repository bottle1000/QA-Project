# QA Practice

회원가입·로그인과 작은 게시판을 연습하는 로컬 서비스입니다.

- [QA 요구사항](docs/qa/requirements.md)
- [실행 및 QA 전달 자료](docs/qa/handoff.md)
- 현재 빌드: **0.1.0**
- 최초 버전 태그: **practice-v0.1.0**

이 폴더에서 `./start.sh` 실행 후 http://127.0.0.1:8087 에 접속하세요.
종료는 `./stop.sh`, 상태는 `./status.sh`입니다.

Spring Boot 3.5.7 / Java 21 / Thymeleaf / JDBC / H2 파일 DB를 사용합니다.
